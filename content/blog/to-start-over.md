I've been trying to create a game for 9 months now. I started by testing several engines: Unity, Unreal, Godot, Love2D, and probably a few others as well.
I ended up choosing Godot because it seemed less bloated than unity/unreal and it felt like designing levels with it would be easier than with an engine without integrated tilemap interface. 

At first I was goind for a top down 2D game but it didn't felt great, so I switch to 2D side scroller view and felt better with it. The style of the game doesn't quite make sense yet but 
I guess it might be somewhat of a metroidvania-like game. After maybe 4 months I didn't felt like the game was feeling fun even tho I still like my gameplay idea... 
Soo... I end up starting all over again the game in odin... After 1 weeks I realize that this was not sustainable and got back to my godot 
project with the idea of having part of the game logic written in odin making the game more fun to make for me.

In some way 8 mounths am starting again.
